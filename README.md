## Dataset

This repository contains the code used to perform the layer-wise
evaluation of CAM techniques in YOLOv8.

The DLC-OD dataset is maintained separately and is publicly available
from:

- Zenodo: https://doi.org/10.5281/zenodo.22553253
- GitHub: https://github.com/FMaghraby/Hand-Sketched-DLCs

The dataset is distributed under the Creative Commons Attribution
4.0 International (CC BY 4.0) license.

Download and extract the dataset before running the experiments.
Then specify the dataset location in `configs/training.yaml` or update
the paths in `data.yaml`.
