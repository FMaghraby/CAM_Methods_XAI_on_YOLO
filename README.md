## Dataset

This repository contains the code used to perform the layer-wise
evaluation of CAM techniques in YOLOv8.

The DLC-OD dataset is available separately from:

- Zenodo: https://doi.org/10.5281/zenodo.22553253
- GitHub: https://github.com/FMaghraby/Hand-Sketched-DLCs

Download and extract the dataset before running the experiments.
Set the dataset location in `configs/training.yaml` or update the
dataset path in `data.yaml`.
